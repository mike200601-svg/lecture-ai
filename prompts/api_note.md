# 课堂笔记整理任务（API 路线）

你要为一节大学理工科课程生成一份完整、忠实、可复习的 Markdown 课堂笔记。

- Session：`{{SESSION_ID}}`
- 课程：`{{COURSE}}`
- 日期：`{{DATE}}`
- 开始时间：`{{START_TIME}}`

本次**只提供录音转录文本**，没有板书照片，也没有课件。
凡是转录里指代不明的地方（"这个式子"、"大家看这张图"、听不清的术语），
明确标注为待确认，**不要用外部知识补全**——那节课到底写了什么，你没有证据。

要求：

1. 以下面的转录为课堂实际讲授的主线，从开场到结束都要覆盖，不要擅自删掉绪论、例子、推导或老师强调。
2. 保留推导过程本身，不要只写结论。老师一步步推的，就一步步记。
3. 不引入转录之外的知识来冒充课堂内容。确有必要的外部补充必须单列并注明"补充说明"。
4. 转录中明显的语音识别错误，若能由上下文唯一确定（例如同一术语前后出现多次），可以更正并在首次出现处注明原文；
   **不能唯一确定的一律保留原样并标注**，不要猜。
5. 输出层次清晰的 Markdown：用 `#`/`##`/`###` 组织，保留重要术语、公式、推导、例题、易错点和考试提示。
6. **数学公式必须用 Obsidian/MathJax 定界符**：行内用 `$...$`，独立公式用单独成行的 `$$`。
   禁止使用 \[ \] 和 \( \) —— 笔记最终存放在 Obsidian Vault 里，
   这两种定界符不会被渲染，会原样显示成裸 LaTeX 源码。
7. **不要输出 YAML front-matter**（开头的 `---` 元数据块）。程序会自己补，你补了会重复。
8. **不要生成 WikiLink（`[[...]]`）**。知识库里的链接由使用者手动建立。
9. 结尾附一节 `## 仍需确认`，列出你无法从转录中确定、需要使用者查课件或问老师的点。
   没有就写"无"。
