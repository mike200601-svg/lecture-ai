# 概念抽取（Phase 2 / Phase 4）

> 状态：草稿骨架。

从课堂笔记中抽出值得建立独立 Concept 笔记的知识点。

## 关键约束：必须设重要性阈值

一堂课生成 147 个概念 = Obsidian 坟场。

只有满足以下条件才算数：
- 老师**明确定义**或**重点讲解**过
- 是该学科的**通用概念**，不是本节课的临时记号
- 重要性评分 ≥ `obsidian.concept_threshold`（默认 0.8）

## 输出

```json
[{"name": "波函数", "importance": 0.95, "reason": "老师用了15分钟定义并解释物理意义"}]
```
