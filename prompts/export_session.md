## 标题层级规范

**全篇只能有一套标题编号，就是课堂话题号：`0.` `1.` `2.` …，子节是 `1.1` `1.2` …，
再下一层是 `1.1.1`。井号数量由编号位数唯一决定**：

| 编号 | 井号 |
|---|---|
| `3.`（1 位） | 顶层内容标题 |
| `3.1`（2 位） | 顶层 +1 |
| `3.1.2`（3 位） | 顶层 +2 |

同一位数的编号**必须**始终用同一个井号数，绝不允许 `0.` 用 `##` 而 `2.` 用 `#`。

### 教材章节号不进标题树

`第1章` / `§1.1` / `1.1.1` 这种**教材**编号和话题号是两套东西，混在一起会让
`0.1`（话题 0 的子节）和 `1.`（话题 1 本身）变成同级兄弟，大纲彻底读不懂。所以：

- 教材对应关系写在**文首说明**和**文末「与教材的对应关系」**里，各写一次。
- 正文中若要标出教材小节的分界，用**引用行**，不要用标题：
  `> 以下对应教材 §1.1.2 对概率波的评述`
- **不要**在正文里挂 `# 第1章 X`、`## 1.1 X` 这种外层壳。

### 两种骨架，按本次课是否有分组层二选一

```
【A】没有分组层（单次课，最常见）
# <文档标题：日期 + 课程>
# 0. 课程基本信息 / 开场      ← 话题固定 h1
## 0.1 子标题                ← 子节固定 h2
# 1. 这门课到底学什么
# 2. 绪论
## 2.1 …
### 2.1.1 …                 ← 三级固定 h3

【B】有分组层（多次课合并、或讲义分成"第一/二部分"）
# <文档标题：日期 + 课程>
# 第一次课｜YYYY-MM-DD        ← 分组层占 h1
## 0. 开场                   ← 话题顺延到 h2
### 0.1 子标题               ← 子节顺延到 h3
> 以下对应教材 §1.1.1 …       ← 教材分界用引用行
## 1. 课堂话题
## 2. 课堂话题
### 2.1 子标题
# 第二次课｜YYYY-MM-DD
# 本节课公式总表              ← 文末附录各节回到 h1
```

选了哪种骨架就**全篇贯彻到底**，不要前半篇话题在 h2、后半篇跑到 h1。

### 其它

- 井号**只能逐级加深**，`#` 后面不能直接出现 `###`。
  没编号的过渡小标题（「正数」「方法 A」「原因 1」）同样要用父级 +1 级。
- 文档标题和分组层标题（`第一次课`、`第一部分`）永远留在 `#`。

## 公式书写规范

笔记最终存放在 **Obsidian Vault**，渲染引擎是 **MathJax 3**（不是 KaTeX，也不是完整 LaTeX）。
很多在 Overleaf 里正常的写法在这里会渲染成**红色的裸源码**。以下为硬性要求：

### 定界符

- 行内公式用 `$...$`，独立公式用**单独成行**的 `$$`（前后各留一个空行）。
- **禁止** `\[ \]` 和 `\( \)`：MathJax 在 Markdown 里默认不认这两种，会原样显示成裸源码。
- `$$` 必须成对，且自成一行，不要和正文写在同一行。

### 只用 MathJax 核心 + AMS 支持的命令

MathJax 没有加载 `textcomp`、`siunitx`、`bm` 等宏包。下列写法**一律禁止**，右侧是替代方案：

| 禁止 | 原因 | 改用 |
|---|---|---|
| `\AA` | 文本模式命令，MathJax 未定义 | `\text{Å}`（直接写 Unicode 字符）或 `\mathring{\mathrm{A}}` |
| `\textdegree`、`\celsius` | textcomp / siunitx | `^\circ`、`\text{℃}` |
| `\textmu` | textcomp | `\mu` 或 `\text{μ}` |
| `\SI{9.8}{m/s^2}`、`\si{...}` | siunitx 未加载 | `9.8\ \mathrm{m/s^2}` |
| `\bm{v}` | bm 宏包未加载 | `\boldsymbol{v}` 或 `\mathbf{v}` |
| `\label` / `\ref` / `\eqref` | Obsidian 无公式交叉引用 | 用文字描述"上式""式 (2)" |

**通用原则：单位和特殊符号优先直接写 Unicode 字符**（Å、℃、μ、Ω、°、±、×），
放在 `\text{}` 里最稳，比任何 LaTeX 文本模式命令都可靠。

### 容易静默出错的几个点

- **百分号必须转义成 `\%`**。MathJax 里 `%` 是注释符，未转义会把该行后面的内容**全部吃掉**，
  而且不报错，只是公式莫名其妙少了一截。
- `\left` 和 `\right` 必须配对；只要一侧时用 `\left.` 或 `\right.` 占位。
- 花括号 `{}` 必须平衡；`\begin{X}` 与 `\end{X}` 必须同名配对。
- 公式里出现中文**必须**包在 `\text{}` 里，例如 `\text{原码}=\text{补码}`，裸中文会被当成变量名连排。
- 多行公式在 `$$` 内部用 `aligned` 或 `cases` 环境，不要用 `align`/`equation`
  （它们本身就带定界符语义，嵌在 `$$` 里会冲突）。

### 输出前自检

生成完成后，逐条扫一遍所有公式，确认：
`$$` 成对 → `\left/\right` 成对 → `{}` 平衡 → `%` 已转义 → 没有用上表里被禁止的命令。
有任何一条不确定，就换成最朴素的写法，**宁可丑一点也不要渲染不出来**。
