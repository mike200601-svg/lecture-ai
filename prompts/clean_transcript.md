# 转录纠错（Phase 2 · 第一层）

> 状态：草稿骨架，Phase 2 实现时打磨。

## 唯一职责

修复 ASR 错误，**不做总结**。

## 必须做

- 修正明显的语音识别错误，尤其是专业术语（参考术语表）
- 补标点、分句
- 去掉无意义口癖（"啊"、"就是说"、"这个这个"）

## 绝对禁止

- 概括、压缩、改写老师的表达
- 删掉任何有信息量的内容

必须原样保留：例子、老师强调的话、考试提示、推导逻辑、常见错误提醒、直觉解释。

## 输入

```text
课程：{{course_name}}
术语表：{{glossary}}
转录片段（含时间戳）：
{{segments}}
```

## 输出

JSON，保持与输入相同的 segment 数量与时间戳，只改 text 字段。
不确定的地方保留原文并在 `uncertain` 字段标注，**不要猜**。
